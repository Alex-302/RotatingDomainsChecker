# TODO: Умная обработка кандидатов за антиботом

## Проблема

Текущая система обрабатывает несколько успешных кандидатов с antibot случайным образом, что приводит к непредсказуемым переключениям между доменами.

На примере PapazSports:

- Найдено 9 кандидатов (942-950.pro) с HTTP 403 + accept_antibot
- Система выбрала 950.pro (случайно)
- При следующем запуске может выбрать другой домен

## Предлагаемое решение

### 1. Стратегии выбора домена при множественных antibot кандидатах

```typescript
enum AntibotStrategy {
  LOWEST_NUMBER = 'lowest_number',    // Домен с минимальным номером
  HIGHEST_NUMBER = 'highest_number',  // Домен с максимальным номером  
  STABLE_FIRST = 'stable_first',      // Первый в детерминированном порядке
  CURRENT = 'current'                 // Текущая логика (случайная)
}
```

### 2. Конфигурация в watchers.yml

```yaml
TMP — PapazSports:
  last_known_mirror: www.papazsports950.pro
  antibot_strategy: lowest_number  # или highest_number, stable_first
  accept_antibot: true
  # ... остальные настройки
```

### 3. Реализация логики выбора

```typescript
private selectAntibotDomain(candidates: AntibotCandidate[], strategy: string): string {
  switch (strategy) {
    case 'lowest_number':
      return this.extractNumber(candidates.map(c => c.domain))
        .sort((a, b) => a - b)[0];
    case 'highest_number':
      return this.extractNumber(candidates.map(c => c.domain))
        .sort((a, b) => b - a)[0];
    case 'stable_first':
      return candidates.sort((a, b) => 
        this.extractNumber([a.domain]) - this.extractNumber([b.domain])
      )[0].domain;
    case 'current':
    default:
      return candidates[0].domain; // текущая случайная логика
  }
}

private extractNumber(domain: string): number {
  const match = domain.match(/(\d+)/);
  return match ? parseInt(match[1]) : 0;
}
```

## Преимущества подхода

### 1. Предсказуемость

- Одинаковый результат при одинаковых кандидатах
- Стабильное поведение системы

### 2. Гибкость

- Разные стратегии для разных сайтов
- Легкое изменение поведения через конфигурацию

### 3. Уменьшение "шума"

- Меньше случайных переключений между доменами
- Более предсказуемые обновления фильтров
