### 2. Разработка схемы именования тестовых доменов

#### 2.1 Паттерновые домены (с числовыми паттернами)

Использовать обезличенные тестовые домены на основе `example.com`:

**Варианты паттернов:**

- `domain[N].tld` → `example001.com`, `example002.com`, ...
- `[N]domain.tld` → `14example.com`, `15example.com`, ...
- `domain[N][text].tld` → `example126xy.com`, `example127xyz.com`, ...
- `www.domain[N].tld` → `www.example375.com`, `www.example3716.com`, ...
- `www.[N]domain.tld` → `www.91example.com`, `92example.com`, ...

**Принципы:**

- Минимизировать количество уникальных базовых имен
- Использовать `.com` как основной TLD для простоты
- Для разных типов паттернов можно использовать разные числовые диапазоны:
  - `example001-099` для `domain[N].tld`
  - `example100-199` для `domain[N][text].tld`
  - `example200-299` для `www.domain[N].tld`
  - `10-99example` для `[N]domain.tld`
- **Гибкость**: При необходимости можно использовать вариации перечисленных доменов (например, `test001.com`, `sample14.com`, `demo126tv.com`), если это помогает избежать конфликтов или путаницы в конкретных тестах

#### 2.2 Непаттерновые домены (без числовых паттернов)

Использовать два подхода:

**A. Простые тестовые домены для общих случаев:**

- `nopattern.com` - основной непаттерновый домен
- `testsite.com` - альтернативный непаттерновый домен
- `example.com` - для случаев где нужен домен без конкретики

**B. Домены с буквенно-цифровым хешем (для имитации реальных случаев):**

- Формат: `example{hash}.com` где `{hash}` - 8-символьный hex
- Примеры: `example0d7142f0.com`, `examplec3a8b9e1.com`
- Использовать когда нужно показать что домен не соответствует паттерну
- Хеш генерировать детерминированно (например, от названия теста)

## Примечания

### Преимущества нового подхода

1. **Независимость от реальных доменов** - тесты не зависят от доступности реальных сайтов
2. **Консистентность** - единая схема именования упрощает понимание тестов
3. **Минимализм** - меньше уникальных доменов = проще поддержка
4. **Очевидность** - по имени домена понятно что это тестовый
5. **Гибкость** - легко добавлять новые тестовые домены по той же схеме
