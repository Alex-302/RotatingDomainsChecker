## Задачи

### 1. Уведомления о критических изменениях

Сейчас результаты только записываются в файлы фильтров и коммитятся. Нет активных уведомлений при:

- Все зеркала сайта упали (не найден рабочий домен)
- Домен изменился на нераспознанный паттерн
- Количество неудачных попыток превысило порог

**Варианты реализации:**

- GitHub Actions summary (output `summary_md`)
- Slack/Telegram webhook (через `notifications_webhook` в `config.yml`)
- GitHub Issue автоматически при критических событиях

**Приоритет:** низкий — сейчас отслеживается через GitHub Actions logs.
