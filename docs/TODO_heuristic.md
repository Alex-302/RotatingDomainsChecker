## Задачи

### 1. Множественные числовые группы

**Проблема:** текущий regex распознаёт только одну группу чисел:
```
taraftarium24-patron15.com → только "24" или "15", не обе
domain123test456.com → только "123"
```

**Решение:** расширить `generateCandidates()` для распознавания и инкремента последней числовой группы в домене:
```
taraftarium24-patron15.com  → 16, 17, 18... (последняя группа)
domain123test456.com        → 457, 458...
```

### 2. Список доменов в last_known_mirror

**Проблема:** `last_known_mirror` — одно значение, но иногда нужно отслеживать несколько зеркал одного сайта
одновременно.

**Решение:** поддерживать массив или строку с разделителями:
```yaml
site_name:
  last_known_mirror: "example001.com,example002.com"
  # или
  last_known_mirror:
    - example001.com
    - example002.com
```

### 3. Буквенный инкремент

**Сценарий:** сайты с буквенным счётчиком:
```
efendispor1o2.live → efendispor1a2.live → efendispor1b2.live
```

**Приоритет:** низкий — пока нет таких сайтов в `watchers.yml`.
